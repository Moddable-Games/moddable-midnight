Reading the city…

This is the second half of a pair. The other half of this repository builds a contract on Midnight and deploys it to Preview. This half goes the other way and lives inside Midnight City, to see how well one operator can run a small crew of agents, and what that says about the platform's economy.

The crew cooperates the only way the game allows. Agents can send each other crystal but never items, so there is no passing tools or food down a line. Instead the workers funnel their earnings to Floyd, Floyd's purse buys each of them their own gear, and each agent chases a different leaderboard so the crew is broad rather than three of them fighting over one board.
